# 2026 추석 단체선물대장 웹 카탈로그

벤디스 단체선물대장 · 2026년 추석 특판 고객사용 상품 카탈로그.

**바로 보기 → https://yeonhyeon9496-png.github.io/giftvendys/**

## 구성

가격대 11구간 / 카테고리 그리드를 탭으로 전환해 확정 큐레이션 상품을 탐색하고,
원하는 상품을 다중 선택해 담당자에게 문의를 넣는 단일 페이지입니다.

- 상단 고정 **공식 주문 마감 D-day** 배너
- **가격대별 / 카테고리별** 탭 전환 + 상품코드·상품명 검색
- **카드 뷰 / 리스트 뷰** 전환 (9개 항목: 이미지·상품코드·카테고리·상품명·구성·상세설명·원산지·과세여부·가격)
- 다중 선택 → **선택상품으로 문의** (수량 입력, 엑셀·PDF·메일 내보내기)
- **금액 숨기고 보기** — 임직원에게 그대로 공유할 때 사용

## 갱신

`index.html` 은 공급처 상품 시트에서 **활성 상품만** 뽑아 생성한 산출물입니다.
빌드 스크립트는 매입 정보를 포함하므로 이 저장소에 두지 않고 로컬에서 관리합니다.
상품이 바뀌면 로컬에서 다시 빌드해 `index.html` 을 교체·푸시하면 반영됩니다.

## 주의

표시 금액은 부가세 포함 공급가이며 배송비는 별도입니다.
재고·가격은 매입처 사정에 따라 변동될 수 있습니다.
